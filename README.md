# film-director

Showrunner repo for Maxi Universe / Reev Cannon short-form slate.

## Layout
- `storylines/` — one markdown file per project
- `scenes/` — one file per scene (camera plan tables, cut notes)
- `approvals/` — sign-off log with timestamps
- `bible/PRODUCTION_BIBLE.md` — visual identity

Shared master (all bots): `/workspace/film/master/`

Communication: brief-only (subject, one paragraph, deadline, BLOCKING|NON-BLOCKING).
